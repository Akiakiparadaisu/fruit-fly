# FlyLearn — 脳波と学習の実験室

ショウジョウバエのキノコ体を参考にした**機能モデル**で、人の脳波から既知語・未知語を分類し、モデル内の学習過程を可視化するブラウザアプリです。実コネクトーム、生物物理モデル、人の脳の再現ではありません。

## 使い方

1. CSVをドラッグ＆ドロップするか「デモデータで試す」を選択。
2. Cygnus形式では機器情報を自動スキップ。8 EEG列と `Timestamp`、`Software Marker Name` を初期選択します。
3. 「マーカーの値と件数を調べる」で実際の値を確認。既知の初期値は `word_onset_known`、未知側の初期値は提供例で確認した `word_onset_pseudo`。pseudoは擬似語条件を意味し、本人の主観的な未知状態を直接証明するものではありません。完全一致で検出します。`char_onset_known` や `item1_s1_known` を単語提示と二重計上しません。
4. 切り出し範囲を提示時間に合わせて指定（初期値：提示前0.2秒〜提示後0.8秒、1,000 Hz）。`Timestamp` は秒です。
5. 読み込み後に学習を実行。各クラス5試行以上が必要です。試行ID単位で80%学習・20%評価に分けます。
6. 「新しいCSVを分類」で同じ列・前処理の別ファイルに固定モデルを適用できます。イベント形式では指定マーカーが必要。試行ID・特徴量形式では正解ラベルは不要です。推論結果をCSV保存できます。
7. 「学習の可視化」で未知とラベル付けされた評価試行を選択。複製したモデルに「既知」の教師信号を繰り返し与え、スコア・結合・疎な細胞活動を観察します。元の分類モデルは変更しません。

CSVはブラウザ内のWeb Workerでチャンク処理し、サーバーに送信しません。生データはGitに含めていません。UTF-8 / Shift_JISに対応。最大32入力列・50,000試行。試行内の欠損・時刻の不連続・重複・逆転を検出します。重なる提示で途中終了した試行や、不完全な試行は除外します。連続して複数のマーカーがある場合、切り出し開始は指定した単語提示マーカーのみです。後続の `item...` マーカーは表示名に利用します。

## 入力形式

- **Cygnus / 提示マーカー**：時刻、EEG列、疎な提示マーカー。1提示＝1試行。機器情報の後の `Timestamp,...` をヘッダーとして認識。
- **連続脳波 + 試行ID**：各行に試行IDとラベルが必要。各試行8点以上。チャンネルごとの平均・標準偏差・RMS・平均絶対差分を抽出（この形式はトレンド除去を行いません）。
- **特徴量**：1行＝1特徴量ベクトル。ラベル列を指定。試行IDなしでは1行を独立試行と扱います。相関する行がある場合は必ず試行IDを指定してください。

イベント形式の前処理は、試行ごと・チャンネルごとにDCと線形トレンドを除去し、標準偏差・平均絶対差分・Hann窓FFTの帯域パワーの対数（1–4 / 4–8 / 8–13 / 13–30 / 30–45 Hz）を計算します。8チャンネルなら56特徴量です。短い窓では低周波の推定が不安定です。バンドパス、ノッチ、眼球運動・筋電の除去は未実装です。

## モデルと解釈

`src/model.js` はUIから独立した分類関数です。学習用だけで標準化 → 固定乱数の疎な入力結合 → 256ケニオン細胞 → 正の活動上位10%の二値化 → 学習可能なロジスティック出力層、という構成です。結合の初期化と分割は固定シードで再現可能。クラス不均衡は出力層の学習重みで補正します。

```js
import { MushroomBody, train } from './src/model.js';
// x: 同じ前処理・順序の特徴量、y: 未知0 / 既知1、group: 試行ID
const result = train(samples, 60);
const classifier = MushroomBody.fromJSON(result.model);
const knownScore = classifier.predict(featureVector);
const predictedLabel = knownScore >= 0.5 ? 'known' : 'unknown';
```

モデルJSONには前処理設定、特徴量名、モデルパラメータ、学習履歴、評価値を保存します。別の実装から呼び出すときは、必ず同じ前処理と特徴量順序を適用してください。ブラウザ画面でのモデルJSON再読み込みは未実装です。

**スコアは未校正**です。人の知識の確率や医療診断として使えません。可視化は同じ入力に新しい教師信号を与えるモデルの適応実験であり、人が単語を覚えた証拠ではありません。実際の学習を評価するには学習前後の脳波、行動成績、単語の対応が必要です。

試行IDによる分割は同じ試行の混入を防ぎますが、被験者・セッション・同一単語の独立性は保証しません。イベント形式のIDは提示ごとに生成します。時系列ドリフトや同一語の再提示による過大評価に注意し、別セッションで検証してください。モデルのパラメータ調整に評価用データを繰り返し利用すると、評価も楽観的になります。

参考：Caron et al., Nature (2013), “Random convergence of olfactory inputs in the Drosophila mushroom body”; Aso et al., eLife (2014), “The neuronal architecture of the mushroom body provides a logic for associative learning”.

## 開発・テスト

Node.js 22.12以降（検証：24.19.0）、npm。

```sh
npm ci
npm run dev
npm test
npm run test:e2e
npm run build
npm run preview
```

E2EはPlaywright Chromiumを使用。初回は `npx playwright install chromium`。システムChromiumがある環境では `CHROMIUM_PATH=/usr/bin/chromium npm run test:e2e` でも実行できます。

## ブラウザ公開

`dist/` は静的サイトです。mainへのpush時にテスト・ビルド・公開するGitHub Actionsワークフローを用意しています。

GitHubの **Settings → Pages → Build and deployment → Source: GitHub Actions** を設定し、**Actions → Test and deploy GitHub Pages → Run workflow** を実行してください。以後はmainへのpushで更新されます。公開先の想定は `https://akiakiparadaisu.github.io/fruit-fly/` です。これは公開成功を保証する記述ではありません。非公開リポジトリでは契約プランによってPagesを利用できない場合があります。

初回ビルド済みの `gh-pages` ブランチも用意しています。Actionsが使えない場合は **Source: Deploy from a branch → gh-pages / (root)** で静的版を公開できます。この方式はmainの変更を自動反映しません。自動更新には上記のActions方式を使用してください。

ローカルでは `npm run dev` で表示できます。`index.html` を直接開かずHTTPサーバーを使用してください。

## 検証範囲

- 合成データで分類、独立した試行分割、標準化の漏洩防止、学習シミュレーションをテスト。
- Cygnusヘッダー、イベント抽出、帯域特徴量、欠損・重複時刻・不完全試行をテスト。
- ブラウザで読み込み、学習、評価、推論、保存、シミュレーション、モバイル表示を検証。
- 提供された644行の実データ断片では、旧設定の提示後0〜0.6秒で既知1試行・56特徴量を抽出確認。指定された−0.2〜0.8秒の検証には断片の前後を含む元CSVが必要です。
- 元の添付CSV全体は転送上限を超えているため未検証。未知側のマーカーは `word_onset_pseudo` と確認済みですが、実データの分類性能は未確認。実データを合成データの精度で代替評価していません。

## 単語の視覚学習（脳波とは独立）

`#vision` または「単語の視覚学習」タブで開きます。CSVなしで動作します。

1. 「8語を3周学習」で英単語画像を24回提示します。
2. 0.25×再生、一時停止、20 msコマ送りで細胞活動と結合更新を観察できます。タブを離れると停止します。
3. 「自分で単語を見せる」で同じ書体／未学習のserif書体を選んで再認します。テストでは記憶を書き換えません。
4. 初期化して学習信号を「なし」にすると、発火しても記憶が形成されない対照実験になります。
5. 「実験を保存」で結合・提示履歴・学習前後の評価をJSONで保存できます。再読み込み機能はありません。ページを閉じると記憶は消えます。

学習語：APPLE / RIVER / MUSIC / CLOUD / STONE / LIGHT / FOREST / BIRD。
未学習の比較語：MAPLE / RIDER / MAGIC / CROWN / STORE / NIGHT / FLOWER / FISH。

モデル入力は、表示する128×32ピクセル画像のRGBA値だけです。単語文字列、単語ID、テストの正解ラベルはモデルに渡しません。64×16に縮小した明暗と輪郭を正規化し、固定乱数による128視覚投射ユニット、384ケニオン細胞（上位32個を選択）へ伝えます。これは説明用の画像エンコーダであり、ハエの視覚系の配線を復元したものではありません。

KCは漏れ積分発火モデル。刻み5 ms、膜電位時定数20 ms、閾値1、リセット0、不応期10 ms。発火で増加する活動痕跡は100 msで減衰します。1提示650 msのうち0–100 msは注視、100–500 msは画像入力、500–600 msは外部の学習信号、600–650 msは休止。時刻はモデルの時間で、生体の速度を予測しません。

学習信号がある間だけ、活動痕跡に近い記憶スロット（コサイン類似度>0.7、なければ新設、最大32）に対して `w += 0.045 × (正規化した活動痕跡 − w)` を適用し、記憶強度も `s += 0.045 × (1 − s)` で更新します。見覚えスコアは、各スロットとのコサイン類似度×記憶強度の最大値。判定閾値は固定0.72です。記憶読み出しは人工的な連想記憶であり、生物学的なMBONの忠実な再現ではありません。

回路図の発光・スパイクラスタ・膜電位・結合ヒートマップ・学習曲線は実際の計算状態から描画します。細胞配置は模式図、線は実接続の一部です。ヒートマップにポインタを置くと結合の数値を確認できます。

評価は小さな固定セットでの画像再認です。同一書体の再認率と別書体への汎化を分け、未学習語の誤再認も表示します。ブラウザのフォントによって結果は変わります。単語の意味、全脳コネクトーム、実測神経活動、人間の言語理解は実装していません。全脳の機能再現をうたうものではありません。
